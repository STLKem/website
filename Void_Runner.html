About this game

Features
  • First-person parkour inspired by Titanfall 2
  • Strange floating islands in a hostile void
  • Combat against advancing enemies
  • Tutorial arena in the main menu
  • Global leaderboard - survive as long as you can
  • Windows download build (Brackeys Game Jam 2026.1)
Controls
  • WASD - move
  • Shift - toggle sprint
  • Ctrl - crouch
  • Space - jump
  • RMB - dash
  • LMB - fireball
